# Звук і мобільний інтерфейс

На запит власника всі згенеровані записи Ryan видалено. Система записаного аудіо підготовлена, але зараз обидві мови використовують системний голос або текстовий режим. Український резервний голос і мобільне керування описано нижче. Обидві функції можна реалізувати. Попередня відсутність фактичної перевірки не означала технічної неможливості.

## Що виправлено в коді

- Сервіс мовлення очікує завантаження списку голосів через `voiceschanged`, з обмеженням часу очікування. Раніше порожній початковий `getVoices()` одразу спричиняв текстовий режим.
- Для української використовується `uk-UA`. Підбираються лише локальні голоси відповідної мови; інша мова не використовується як заміна.
- Якщо голос уже доступний, `speechSynthesis.speak()` викликається одразу з натискання кнопки, без попереднього асинхронного очікування. Це важливо для браузерних обмежень автовідтворення.
- У налаштуваннях показано знайдені локальні голоси EN та UA і є кнопка перевірки. Окремо пояснюються відсутність голосу, нульова гучність, блокування браузером та помилка пристрою відтворення.
- Карта використовує наданий радар зі збереженням пропорцій. Додані перетягування, масштабування двома пальцями, більші кнопки, мобільна панель фільтрів, нижня навігація з усіма розділами та відступи під системну панель телефона.

## Чому звук може бути відсутній на конкретному пристрої

Браузер використовує голоси, доступні в ОС і самому браузері. Наявність української клавіатури чи мови інтерфейсу не гарантує, що встановлено український голос синтезу мовлення. Крім того, деякі доступні браузеру голоси є мережевими. Callout не використовує їх автоматично, щоб офлайн-режим і локальна обробка залишалися правдивими.

1. Відкрийте Callout → Налаштування → Відтворення й аудіювання. Перегляньте рядки EN та UA.
2. Якщо потрібного локального голосу немає, перевірте підтримку та встановлення голосового пакета у вибраному рушії синтезу мовлення ОС. Доступність залежить від ОС, браузера й рушія; не кожна комбінація надає український офлайн-голос.
3. Установіть ненульову гучність у застосунку та системі. Перевірте правильний вихід: динамік, навушники або Bluetooth.
4. Натисніть «Перевірити голос мови навчання» або динамік у вправі. Якщо браузер заборонив звук, перевірте дозвіл відтворення для цього сайту й повторіть натискання.
5. Якщо локального українського голосу немає навіть після налаштування ОС, наступний крок — додати окремий український записаний аудіопакет (інтеграція англійського Ryan підготовлена, але записи видалено), який кешуватиметься разом із застосунком. Інший варіант для нативної оболонки — окремий адаптер офлайн-TTS. Українські записи та нативний адаптер не позначені готовими. Англійські записи наразі відсутні; дивіться recorded-audio.md.

Список голосів може завантажуватися асинхронно: [MDN: SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis). Реальні голоси залежать від браузера: [Web Speech API specification](https://github.com/WebAudio/web-speech-api/blob/main/index.bs).

## Як відкрити на телефоні

На своєму комп’ютері в папці проєкту:

```sh
npm start -- --host 0.0.0.0
```

Комп’ютер і телефон мають бути в одній локальній мережі. Відкрийте на телефоні адресу `Network`, яку надрукує Vite, наприклад `http://192.168.1.20:5173`. Не вводьте `127.0.0.1` з телефона: це адреса самого телефона. Якщо з’єднання не встановлюється, перевірте адресу мережевого інтерфейсу та доступ до порту в локальному брандмауері. Використовуйте dev-сервер у своїй довіреній мережі.

Це відкриває адаптивну Web-версію; APK для цього не потрібен. За [документацією Vite](https://vite.dev/config/server-options), `--host 0.0.0.0` дозволяє доступ через мережеві інтерфейси. Стандартна команда `npm start` залишається доступною лише локально.

Для перевірки офлайн-кешу та встановлення PWA потрібна production-збірка на HTTPS (або localhost на самому пристрої). Звичайний HTTP через LAN придатний для перевірки верстки, але не є перевіркою встановлення офлайн-PWA. Нативна Android-оболонка — окремий етап.

## Що заважало перевірці в середовищі агента

Інструмент керування браузером повертає `The browser access host is unavailable`, а спроба підняти локальний dev-сервер повертала `listen EPERM`. Це обмеження середовища виконання, а не доказ непрацездатності сайту на вашому комп’ютері чи телефоні. Код, збірку й автоматичні тести можна перевірити тут; фактичний звук, сенсорні жести, ширини екрана та встановлення PWA потрібно перевірити в доступному браузері/на пристрої. Не потрібно вимикати античіт, захист браузера чи системні механізми безпеки.

Після оновлення production-версії закрийте старі вкладки Callout та відкрийте застосунок знову, щоб активувався новий офлайн-кеш. Не очищайте IndexedDB для оновлення інтерфейсу: там зберігається прогрес.
